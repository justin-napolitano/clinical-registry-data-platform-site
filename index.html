Product summary

One governed runtime for registry intake, metadata, validation, and review.

This site explains how clinical registry source files move through runtime generation, promoted metadata, encrypted payload storage, Snowflake deployment artifacts, and human review surfaces.

Current state

The consolidated runtime has generated successful metadata artifacts across the registry set. STS is the most complete interactive review example, while the coverage page shows the broader generated object inventory.

Data handling

PHI-bearing upload CSVs are excluded from Git. Promoted metadata and SQL live in Git; generated CSV payloads live in a local encrypted data dump.
